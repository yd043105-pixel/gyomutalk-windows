# 교무톡 0.1.2

- 수업 교체 화면이 창 크기에 맞춰집니다. 요일·교시와 ‘교체 신청 제출’이 항상 보이고, 변경 기록은 그 아래에 나옵니다.
- 기초시간표를 학년 칸마다 올립니다. 한 학년만 다시 올려도 다른 학년은 그대로 남습니다.
- 묶음수업을 학년 → 과목 → 분반 순으로 고릅니다.
- 창을 최대화해도 위아래가 잘리지 않습니다.
- 학교 관리자가 끈 기능은 메뉴에 보이지 않습니다.

이번 버전은 학교 서버와 교직원용 메신저 중 어느 쪽을 먼저 업데이트해도 됩니다. 기능 설정은 양쪽을 모두 업데이트한 뒤에 적용됩니다.
