# 교무톡 0.0.8

- 화면 전체를 새 '맑은 청' 디자인으로 바꿨습니다. 교직원마다 이름 첫 글자 프로필과 접속 상태가 보입니다.
- 확인·안내 창이 교무톡 디자인으로 바뀌고, 지우기·나가기처럼 되돌릴 수 없는 버튼은 빨간색으로 구분합니다.
- 교무톡을 두 번 실행해도 창이 하나만 열리고, 이미 실행 중인 창이 앞으로 나옵니다.
- 엑셀에서 열어 둔 시간표 파일도 그대로 올릴 수 있습니다.
- 설문의 객관식 문항은 선택지를 바로 눌러 고르고, 교체 신청 현황은 상태를 색으로 구분합니다.
- 학교 서버 연결 문제를 알기 쉬운 말로 안내하고, 메시지 회수·파일 저장 결과를 창 아래에 표시합니다.

학교 서버를 먼저 업데이트한 뒤 교직원용 메신저를 업데이트하세요.
